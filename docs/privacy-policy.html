Privacy Policy for Weather

App Name Weather

1. Overview & Actual Data Practices

Weather (package name com.aistudio.weather.glsmph) is an Android weather forecast application developed by Antonee. This Privacy Policy accurately describes how the application handles device permissions, location coordinates, city search queries, notifications, local device storage, and third-party libraries based strictly on its actual source code.

  • No Proprietary Backend Server: The developer does not operate any backend server or database. The app connects directly from your Android device to the public Open-Meteo APIs over encrypted HTTPS.
  • No Personal Identity Collection: The app does not require registration and never collects your name, email address, phone number, contacts, media files, or payment details.
  • No Ads or Behavioral Tracking: The app contains zero advertising SDKs, zero analytics trackers, and zero user profiling code.

2. Android Permissions Used

The application declares only the following five permissions in AndroidManifest.xml:

Permission Category Actual Usage in Weather
android.permission.INTERNET Install-time Used to fetch live weather forecasts (https://api.open-meteo.com/v1/forecast) and city search results (https://geocoding-api.open-meteo.com/v1/search) over HTTPS.
android.permission.ACCESS_NETWORK_STATE Install-time Used via ConnectivityManager to check network availability and switch cleanly to locally cached weather data when offline.
android.permission.ACCESS_COARSE_LOCATION Runtime (Optional) Requested only on demand when you tap Use My GPS and accept the in-app Local Weather Access disclosure dialog.
android.permission.ACCESS_FINE_LOCATION Runtime (Optional) Requested alongside coarse location when you tap Use My GPS to obtain foreground GPS coordinates for local weather lookup.
android.permission.POST_NOTIFICATIONS Runtime on Android 13+ (Optional) Requested only when you enable notifications or tap Send Test Weather Notification in Settings on Android 13 (API 33) or newer.

Note: The application does not request or use background location permission (ACCESS_BACKGROUND_LOCATION).

3. Location Usage & Manual City Selection

  • On-Demand Foreground Location: Location access is never requested automatically on startup. When you tap Use My GPS, an in-app dialog explains why location access is needed and offers Allow Location or Search City Instead.
  • How Coordinates Are Used: When granted, your latitude and longitude are read in the foreground via FusedLocationProviderClient (or system LocationManager fallback), resolved to a city name using the Android system Geocoder, and sent over HTTPS to the Open-Meteo Forecast API to load your weather forecast.
  • Works Without Location Permission: You can decline location permission and use all forecast features by searching and saving cities manually in the Cities & Search tab.

4. Weather API & Network Communication

  • Open-Meteo Forecast API (https://api.open-meteo.com/v1/forecast): Receives the latitude and longitude of your selected city over HTTPS to return current weather, 24-hour hourly forecast, and 10-day forecast metrics.
  • Open-Meteo Geocoding API (https://geocoding-api.open-meteo.com/v1/search): Receives the city name you type into the search box (sanitized, up to 80 characters) over HTTPS to return matching cities and coordinates.
  • Standard HTTPS Metadata: As with any standard internet request, Open-Meteo's servers receive standard HTTP metadata (such as your IP address) to deliver the response.
  • HTTPS-Only Enforcement: Cleartext HTTP traffic is blocked (android:usesCleartextTraffic="false"), and HTTP request logging is restricted strictly to debug builds (disabled in release builds).

5. Local On-Device Storage & Cloud Backup Policy

  • Jetpack DataStore (weather_phase5_preferences): Stores your theme preference, temperature unit (°C/°F), animation quality settings, notification settings, saved city list (name, region, coordinates, favorite flag), and cached weather snapshots locally on your device.
  • Widget SharedPreferences (weather_widget_shared_state): Stores the latest formatted weather summary displayed on the Android Home Screen Widget.
  • Cloud Backup Disabled: android:allowBackup="false" is enforced in the manifest, and backup_rules.xml / data_extraction_rules.xml exclude local preferences and cached coordinates from automatic cloud backup.
  • Deleting Your Data: You can delete individual cities, tap Clear All in the Cities & Search screen to remove all saved locations, or clear app storage / uninstall the app at any time.

6. Notifications, Background Refresh & Widget

  • Optional Weather Notifications: When enabled in Settings, the app posts local notifications for Daily Weather Summaries, Rain Alerts, and estimated Severe Weather Advisories.
  • Periodic Background Sync (WorkManager): When periodic refresh is enabled, WeatherBackgroundSyncWorker refreshes forecast data using the stored coordinates of your saved city in DataStore when connected to the internet, updating the local cache and Home Screen Widget. Setting refresh to Manual Only with notifications disabled cancels all background work.

7. Third-Party SDKs & Libraries Disclosed

  • Open-Meteo APIs (https://open-meteo.com) – Weather forecast and city geocoding data licensed under CC BY 4.0 (Terms & Privacy).
  • Google Play Services Location (com.google.android.gms:play-services-location) – Used for on-device foreground GPS lookup when location permission is granted (Google Privacy Policy).
  • Square Retrofit, OkHttp & Moshi – Open-source (Apache 2.0) HTTPS client and JSON serialization libraries running on-device.
  • AndroidX Jetpack Libraries (Compose, DataStore, WorkManager, Lifecycle, Activity, Core-KTX) – Official open-source (Apache 2.0) Android Jetpack libraries.

8. Children's Privacy

The Weather application is a general-audience utility app and does not knowingly collect personal information from children or any other users.
